# Componentes UI reutilizables

Inventario para agentes. Antes de inventar un control, buscar aquí y en `src/shared/components/`. Evidencia: archivos citados. Estado: `VERIFICADO` en código 2026-09-18.

## Estructura

- `ui/`: solo componentes de shadcn.
- `shell/`: cabecera (`shell/header/`), barra lateral, tab bar, layout de secciones, pending de navegación y logo.
- `forms/`: campos, selectores, ruedas y `FormScreen`.
- `sheets/`: `SheetHeader`, `SheetBody` y las clases de la hoja ancha y flotante.
- `fab/`: acción flotante y su contexto.
- `agent-chat/`: disparador del overlay global del agente; el overlay vive en el módulo de Inteligencia.
- `feedback/`: carga, placeholder de módulo y centinela de lista infinita.
- `data-display/`: `SummarySection` y sus filas.
- `settings/`: filas y secciones de ajustes.

## Referencia viva

Las galerías de referencia viven en Ajustes → Apariencia, con un atajo para cada una. [`/settings/appearance/components`](../../src/modules/galleries/README.md) es el índice con búsqueda de todos los componentes de `src/shared/components/ui/` y de los wrappers de dominio, agrupados por propósito: entradas y campos, selectores, botones y acciones, diálogos y sheets, tabs y chips, listas y filas, encabezados y secciones, estados, avisos y toasts, montos y fechas, gráficos y anillos, y estructura. Cada categoría abre su lista por ruta (`/settings/appearance/components/<categoría>`) y cada componente su documentación (`/settings/appearance/components/<categoría>/<componente>`), con vista previa y código en tabs, descripción, cuándo usarlo y cuándo no, código de uso con botón de copiar, composición, variantes y estados, y API con la ruta de importación. [`/settings/appearance/cards`](../../src/modules/galleries/README.md) monta las cards de cada entidad con sus variantes. Antes de crear un control, se busca ahí; si falta, se agrega con su issue. Mantenimiento: [`src/modules/galleries/README.md`](../../src/modules/galleries/README.md).

La galería monta el componente real de cada patrón. Los que no se pueden ver aislados no aparecen ahí y su contrato vive en la tabla y en el código: `Fab` y `ExpandableFab` van fijos a la ventana, `AsyncRegion`, `MissingRecord` y `RecordOptionsSheet` necesitan datos o una ruta, `ModuleSectionLayout` es un layout de ruta y `LinkPendingOverlay` solo pinta durante una navegación real (la galería muestra `PendingSurface`, la superficie que lo dibuja).

## Fecha y hora — no usar inputs nativos

**Prohibido** en UI de producto: `<input type="time">`, `<input type="date">`, y `Input` con esos `type`. La rueda vive en [`src/shared/components/forms/wheel-picker.tsx`](../../src/shared/components/forms/wheel-picker.tsx). En pantalla siempre va dentro de [`WheelField`](../../src/shared/components/forms/wheel-field.tsx): la misma fila que `FinanceDateField`.

| Necesitas                   | Usar               | Valor                                                                              |
| --------------------------- | ------------------ | ---------------------------------------------------------------------------------- |
| Cualquier rueda en pantalla | `WheelField`       | Fila (icono, valor, chevron), panel a ancho completo y `Listo` abajo a la derecha  |
| Hora de reloj               | `TimePairWheels`   | Contenido del panel. `HH:mm` 24 h (ej. `"09:00"`)                                  |
| Duración (horas + minutos)  | `DurationWheels`   | Contenido del panel. `HH:mm` de duración (ej. `"01:30"` = 90 min). Sin a. m./p. m. |
| Fecha                       | `FinanceDateField` | `WheelField` + `DateWheels`. `YYYY-MM-DD`, atajos “Hoy” / “Listo”                  |
| Un día dentro de un rango   | `DayWheel`         | `WheelField` + una rueda. String decimal (`"15"`), `min` / `max`                   |
| Varios días del mes         | `DayListField`     | Cada día es un `DayWheel`                                                          |
| 2 a 5 opciones exclusivas   | `ChoiceGrid`       | Celdas con icono en el color del módulo y, al elegir, borde más grueso y check     |

Toda fecha o hora visible sale de `src/shared/lib/date-format.ts`, con el locale del perfil; ninguna pantalla fija `es` ni usa `toLocaleDateString`/`toLocaleTimeString`.

`TimePairWheels`, `DurationWheels` y `DateWheels` no se montan sueltos en una vista. `TimePairWheels` muestra hora 12 h + minutos + periodo a. m./p. m. `DurationWheels` muestra horas 00–24 + minutos, sin periodo. Los minutos se configuran con `minuteStep`: `1` (00–59), `5` o `10`. Convierte reloj con `hm24To12Parts` / `hm12To24` y duración con `durationMinutesToHm` / `hmToDurationMinutes` en `src/shared/types/wheels.type.ts`.

```tsx
import { WheelField } from "@/src/shared/components/forms/wheel-field"
import { TimePairWheels } from "@/src/shared/components/forms/wheel-picker"
import { ClockIcon } from "lucide-react"

;<WheelField label="Hora" valueLabel="9:07 a. m." icon={ClockIcon}>
  <TimePairWheels
    value="09:07"
    minuteStep={1}
    onChange={(next) => {
      // next es "HH:mm" 24 h
    }}
  />
</WheelField>
```

Un `Input type="number"` para cantidades **sí** es válido; no es fecha/hora. Duraciones con horas y minutos van en `DurationWheels` dentro de `WheelField`, no en un input numérico.

## Collapsible para elegir un dato

`WheelField` (y `FinanceDateField`, `DayWheel`, que lo usan) es la presentación de una rueda:

- El panel abierto ocupa **todo el ancho** del bloque que lo contiene. Si el disparador comparte fila con otro control, ese control va en `aside`, para que el panel siga a ancho completo.
- El pie del panel deja los atajos a la izquierda (`Hoy`, y `Sin fecha` si aplica). A la derecha, al fondo, va un botón `Listo`. Se habilita cuando ya hay un valor elegido. Al pulsarlo, cierra el panel. El valor ya quedó escrito al elegirlo.
- `ChoiceGrid` recibe `accentColor` del módulo. El icono va sobre un fondo tenue de ese color. La celda elegida no se rellena: lleva un borde más grueso de ese color y un check.

Cada hoja compone `Drawer`, `DrawerContent`, `SheetHeader`, `SheetBody` y `DrawerFooter`. Un selector que se abre desde una hoja se monta dentro de su `Drawer` para apilarse como drawer anidado.

### Hoja por ruta

Toda hoja se abre con la URL, no con un estado local: `useSheetParam(key)` y, cuando la hoja muestra un registro, `sheetId`. En Finanzas la clave sale de `FINANCE_SHEET_KEYS`; en Ajustes, de `SETTINGS_SHEET_KEYS`, que comparten Privacidad y Finanzas para el vaciado (`wipeData`). Regla completa: [`sheet-url-route.mdc`](../../.cursor/rules/sheet-url-route.mdc).

```tsx
const category = useSheetParam(FINANCE_SHEET_KEYS.category)
const editing = useSheetListEntity(
  category.open,
  category.sheetId,
  categoriesQuery.data,
  categoriesQuery.isPending,
  category.setOpen
)

onClick={() => category.setOpen(true, item.id)}

<CategorySheet
  open={category.open}
  onOpenChange={category.setOpen}
  category={editing}
/>
```

Un sheet informativo (ayuda, glosario, historial, «Novedades») también lleva ruta, y una hoja anidada (un selector dentro de un formulario que ya está en hoja) usa el segundo parámetro (`?picker=<clave>`) con `usePicker` de `src/shared/hooks/use-picker` (#251). Un `AlertDialog` de confirmación no lleva ruta: Esc cancela, un clic fuera no cierra. Las claves de los ajustes de Finanzas también son constantes (`financeSettingsDisplay`, `financeSettingsMonth`, `financeSettingsMovements`, `financeSettingsFixedIncome`, `financeSettingsSubscriptions` y `financeSettingsNotifications`), y la calculadora de importes usa una clave por monto (`?picker=calculator-<monto>`, por ejemplo `calculator-card-limit`): dos montos visibles a la vez no comparten clave, así se abre solo la calculadora del campo pulsado. Una hoja nueva se abre siempre por ruta.

`ReleaseNotesSheet` es la única hoja global del shell: aparece una vez por versión. La última versión vista vive en el perfil (`lastSeenReleaseVersion`; se marca con `PATCH /users/me/release-notes-seen`), y `localStorage` (`releaseNotesSeenVersion`) queda solo como caché para no mostrarla mientras el perfil carga. En la primera visita la versión actual se marca en silencio, sin hoja. El componente de `src/shared` es presentacional: recibe la versión vista y el marcado desde `ReleaseNotes` (`src/modules/settings`).

Un atajo del `RecordOptionsSheet` que abre otro sheet o navega a otra vista no cierra el menú antes: cerrarlo usa `router.back()`, y ese retroceso cancela la apertura pedida en el mismo click. El sheet nuevo reemplaza al menú en la URL, y la navegación a otra ruta lo desmonta.

Una lista larga dentro de un sheet lleva búsqueda. El texto ignora mayúsculas y acentos. Cada coincidencia destella una vez (`animate-search-flash`). Si el ítem está dentro de un collapsible cerrado, ábrelo solo cuando la coincidencia es un hijo: un padre que coincide se queda cerrado para que sus hijos no tapen el resultado.

Toda vista de lista (dentro o fuera de un sheet) trae más filas al bajar: scroll infinito, sin botones de página. La regla y el contrato por cursor viven en [`list-infinite-scroll.mdc`](../../.cursor/rules/list-infinite-scroll.mdc).

**Módulo hoja** (Keep Awake): hero + iconos + sheets. **No** uses `Tabs*` para Recordatorio/Historial/ajustes en la misma página. Eso es chrome de hoja, no secciones. Molde: [module-conventions.md — Módulo hoja (UX)](./module-conventions.md#módulo-hoja-ux). `Tabs*` solo si hay ≥2 superficies locales que **no** merecen ruta y **no** es un módulo hoja. El tab activo se guarda en la query (`tab`) para que Atrás lo recupere; un sheet que reinicia su tab pasa `persist={false}`. El chip se desliza, el panel entra con presencia y un swipe horizontal cambia de tab.

Keep Awake reminder: [`keep-awake-reminder-sheet.tsx`](../../src/modules/keep-awake/components/keep-awake-reminder-sheet.tsx) (`Guardar` activa). Aviso al due: [`keep-awake-reminder-prompt.tsx`](../../src/modules/keep-awake/components/keep-awake-reminder-prompt.tsx) (`floating`). Temporizador: [`keep-awake-duration-controls.tsx`](../../src/modules/keep-awake/components/keep-awake-duration-controls.tsx) (popover + `DurationWheels`). Horario silencioso: [`edit-quiet-hours-sheet.tsx`](../../src/modules/settings/components/sheets/edit-quiet-hours-sheet.tsx).

## Cards por entidad

Una entidad de Finanzas se pinta con su card y la variante que corresponda; nunca con una fila propia. La variante es una prop del mismo componente, no un componente paralelo. Regla obligatoria: [`entity-cards.mdc`](../../.cursor/rules/entity-cards.mdc). Referencia viva: `/settings/appearance/cards` ([README](../../src/modules/galleries/README.md)).

- **Completa** (`variant="full"`, por defecto): listas y cabecera del detalle.
- **Compacta** (`variant="compact"`): la entidad es un dato de otra cosa (un vencimiento, un método de pago, una vinculación, un resumen).
- **Inline** (`variant="inline"`): mención dentro de una línea de texto.
- Las cards aceptan `onPress` o `href`, `disabled` y, en selectores, `selected` (anillo de 2 px y marca).
- Si la entidad no tiene card, se crea en su módulo y se añade a la galería `/settings/appearance/cards` antes de usarla. Una proyección de otra entidad (una línea de estado de cuenta, un extra importado) se adapta a la fila canónica; no se dibuja una fila nueva.

## Una sola fuente de verdad

Un patrón se pinta siempre con el mismo componente. Si cambia un detalle, cambia en el componente y se ve en todas partes; no se crea una copia «más simple» para una vista. Regla obligatoria: [`ui-single-source.mdc`](../../.cursor/rules/ui-single-source.mdc). Referencia viva: `/settings/appearance/components` y `/settings/appearance/cards` ([README](../../src/modules/galleries/README.md)).

| Patrón                                  | Componente canónico                                                                                                                                                                                                          | Estado                                      |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| Confirmar una acción destructiva        | `AlertDialog` + `AlertDialogMedia` + `Spinner`, compuesto en cada pantalla; el guarda de un sheet con cambios es `useDiscardChanges`                                                                                         | Completo                                    |
| Cerrar un sheet                         | El botón Cancelar o Cerrar del `DrawerFooter` llama al `onOpenChange` de la hoja; si no hay cierre, se omite el botón ([`sheet-layout.ts`](../../src/shared/components/sheets/sheet-layout.ts))                              | Completo                                    |
| Cerrar un sheet con cambios sin guardar | `useDiscardChanges` ([`use-discard-changes.tsx`](../../src/modules/finance/shared/hooks/use-discard-changes.tsx))                                                                                                            | Completo                                    |
| Monto en pantalla                       | `Money` ([`money.tsx`](../../src/modules/finance/shared/components/money.tsx)) sobre `formatFinanceMoney`; escribirlo, `FinanceMoneyField`                                                                                   | Completo                                    |

## Formularios de Finanzas

Viven en `src/modules/finance/shared/components/forms/`. No copiarlos a otros módulos; sí reutilizar el patrón:

- `FinanceDateField` → fecha
- `FinanceMoneyField` → monto con teclado y calculadora; `FinanceCurrencyPickerSheet` → moneda con bandera; `ToggleGroup` → segmentos
- Cuenta o tarjeta: `DestinationTrigger` + `DestinationPickerSheet`; institución: `InstitutionTrigger` + `InstitutionPickerSheet`; categoría: `CategoryTrigger` + `CategoryPickerSheet`; país: `CountryTrigger` + `CountryPickerSheet`. `DestinationPickerSheet` acepta `noneLabel` cuando la elección puede quedar vacía. No se elige un catálogo largo en un `Select` inline.
- Cerrar un formulario con cambios sin guardar: `useDiscardChanges` (`src/modules/finance/shared/hooks/use-discard-changes.tsx`).
- `Field` / `FieldLabel` / `FieldError` (`src/shared/components/ui/field.tsx`) → etiqueta y error en cualquier control con etiqueta, no solo en un formulario que envía
- Campos de texto y select, en cualquier vista: icono líder del tipo de dato (`Field` + `InputGroup` con `InputGroupAddon`, `SelectTrigger` con `icon`). Placeholder solo como ejemplo o formato. Un catálogo largo abre hoja, no un `Select` inline. Estado binario en una fila: icono + `aria-label`, no la etiqueta cruda.

### Botón de registrar o guardar

Estado del botón de envío: [`.cursor/rules/form-submit-disabled.mdc`](../../.cursor/rules/form-submit-disabled.mdc). Las reglas compartidas (`isPositiveAmountInput`, `isLedgerTargetInput`) viven en [`ledger-form.ts`](../../src/modules/finance/shared/lib/ledger-form.ts) con su spec.
